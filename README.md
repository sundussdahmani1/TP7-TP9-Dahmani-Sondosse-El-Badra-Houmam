## TP7 — Explorateur de pays

Application Vue 3 avec Vue Router qui consomme l'API [RestCountries](https://restcountries.com/).

**Fonctionnalités :**
- Liste de tous les pays avec recherche en temps réel
- Fiche détaillée d'un pays (drapeau, capitale, région, population)
- Page 404 personnalisée
- Navigation avec Vue Router

**Lancer le projet :**
```bash
cd TP7
npm install
npm run dev
```

---

## TP9 — Météo en direct

Application Vue 3 qui consomme l'API [OpenWeatherMap](https://openweathermap.org/).

**Fonctionnalités :**
- Recherche de ville avec debounce (400ms)
- Autocomplétion des villes via l'API de géocodage
- Météo actuelle (température, ressenti, humidité, icône)
- Prévisions sur 5 jours regroupées par jour (min/max)
- Historique des 5 dernières villes consultées
- Basculement °C / °F

**Lancer le projet :**
```bash
cd TP9
npm install
cp .env.example .env   # Renseigner votre clé API OWM
npm run dev
```
